# Top Waterproofing Companies in Toronto

Розділений проект - порівняльний рейтинг водопровідних компаній Торонто.

## Структура проекту

```
waterproofing-companies/
├── index.html                 # Основна HTML сторінка
├── styles/
│   ├── main.css              # Основні стилі та макет
│   └── profile.css           # Стилі для модального вікна профілю
├── js/
│   ├── main.js               # Основна логіка та рендеринг карток
│   └── profile.js            # Допоміжні функції для профілю
├── data/
│   └── companies.js          # Дані компаній
└── README.md                 # Цей файл
```

## Файли

### HTML
- **index.html** - Основна сторінка з навігацією, hero-секцією та контейнером для карток компаній

### CSS
- **styles/main.css** - Основні стилі включаючи:
  - Колірну схему (Deep Water theme)
  - Layout карток компаній
  - Рейтинги та метрики
  - Responsive дизайн для мобільних пристроїв
  - Промо-баннер

- **styles/profile.css** - Стилі для вспливаючого профілю компанії:
  - Slide-in анімація
  - Інформаційні панелі
  - Рейтинги та графіки
  - Responsive для планшетів

### JavaScript
- **js/main.js** - Основна функціональність:
  - Рендеринг карток компаній з даних
  - Обробка кліків на кнопки
  - Відкриття/закриття модальних вікон профілю
  - Управління UI інтеракціями

- **js/profile.js** - Допоміжні функції:
  - Підтримка клавіші Escape для закриття
  - Плавне прокручування
  - Share функціональність
  - Analytics helpers

### Дані
- **data/companies.js** - Масив об'єктів з інформацією про компанії:
  - Рейтинги та метрики
  - Контактна інформація
  - Описи та факти
  - Область фокусу (услуги)

## Як запустити

1. Відкрийте **`index.html`** у браузері (основна сторінка проекту)
2. Картки компаній автоматично завантажуватимуться з `data/companies.js`
3. Клікніть "VIEW PROFILE" на будь-якій картці, щоб переглянути детальну інформацію
4. Клікніть "VISIT SITE" для переходу на вебсайт компанії

**Примітка:** `manifest-style.html` - це оригінальний монолітний файл (для історії), основна сторінка це `index.html`

## Як додати компанію

Відредагуйте `data/companies.js` і додайте новий об'єкт до масиву `companies`:

```javascript
{
  id: 'company-id',
  rank: 6,
  name: 'Company Name',
  logo: 'CN',
  logoColor: '#hexcolor',
  bestFor: 'Description',
  isTopPick: false,
  rating: 4.5,
  ratings: {
    reputation: 4.5,
    breadth: 4.6,
    warranty: 4.5,
    availability: 4.4
  },
  // ... інші поля
}
```
