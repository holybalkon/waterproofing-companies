# Промт для Kiro: Створення сайту рейтингу компаній

Створи сайт-рейтинг компаній за таким описом:

## Вимоги проекту

**Назва:** Рейтинг компаній [КАТЕГОРІЯ]
**Мета:** Відобразити топ компанії в категорії з рейтингами, профілями та інформацією для контакту.
**Дані будуть додані пізніше** — на цьому етапі створити готовий шаблон зі структурою даних.

## Архітектура проекту

```
src/
├── index.html           (ТОЧКА ВХОДУ - головна сторінка)
├── styles/
│   ├── main.css         (основні стилі, layout, картки)
│   └── profile.css      (модальний профіль компанії)
├── js/
│   ├── main.js          (логіка рендерингу, обробка подій)
│   └── profile.js       (закриття модалю, утиліти)
└── data/
    └── companies.js     (масив компаній - ДО ЗАПОВНЕННЯ)
```

## Структура сторінки

1. **Хлібні крихти** — навігація з посиланнями на домашню сторінку
2. **Hero секція** — назва, опис, дата оновлення
3. **Вступний текст** — як компанії вибиралися
4. **Експертна цитата** — з фото та ім'ям експерта
5. **Методологія** — пояснення рейтингу
6. **Список компаній** — картки з рейтингами
7. **Промо-баннер** — пропозиція "Почати"
8. **Модальний профіль** — детальна інформація компанії при клікові

## Дизайн

- **Палітра:** Холодна палітра (блакитний #0c8ce9, teal #0fb8a8, чорний #0f1b2d)
- **Шрифт:** Plus Jakarta Sans (400, 500, 600, 700, 800)
- **Іконки:** Unicons v4.0.8
- **Responsive:** Адаптивний для мобільних (320px), планшетів (640px), десктопу (1100px)

## Компоненти

### Картка компанії
- Номер рейтингу (gradient фон)
- Логотип (з кольором)
- Назва компанії
- "Best for" опис
- Рейтинги (загальна оцінка + 4 метрики)
- Факти компанії
- Опис
- Послуги (іконки)
- Кнопка "VIEW PROFILE" + "VISIT SITE"

### Профіль компанії (модал)
- Header з логотипом та рейтингом
- About секція
- Company Facts (дата заснування, гарантія)
- Service Ratings (з графіками)
- Focus Areas (чіпси з услугами)
- Кнопки (Visit Website, Share)

### Top Pick картка
- Спеціальна стрічка з інформацією
- Виділена обв'язка вздовж верхньої частини

## Функціональність

- ✅ Рендерування карток з даних `companies.js`
- ✅ Клік "VIEW PROFILE" → відкриває модал з деталями
- ✅ Клік "VISIT SITE" → відкриває вебсайт в новій вкладці
- ✅ ESC-ключ → закриває модал
- ✅ Клік ззовні модалю → закриває модал
- ✅ "GET STARTED" кнопка → показує повідомлення (або форму)
- ✅ Адаптивність для всіх пристроїв

## Структура даних компанії (companies.js)

Кожен об'єкт компанії повинен містити:

```javascript
{
  id: 'company-id',               // унікальний識别符
  rank: 1,                        // позиція в рейтингу
  name: 'Company Name',
  logo: 'CN',                     // 2-3 букви для логотипу
  logoColor: '#0c8ce9',           // hex колір
  bestFor: 'Best for...',
  isTopPick: true/false,          // спеціальна мітка
  sponsored: '#1 FEATURED',       // опціонально
  rating: 4.9,                    // загальна оцінка (0-5)
  ratings: {
    reputation: 5.0,
    breadth: 4.8,
    warranty: 4.7,
    availability: 4.6
  },
  facts: [
    { icon: 'uil-calendar-alt', text: 'Since YYYY' },
    { icon: 'uil-home', text: 'Description' }
  ],
  description: 'Full company description...',
  highlight: 'Key highlight...',
  focusAreas: [
    { icon: 'uil-raindrops', label: 'Service Name' }
  ],
  platform: 'Platform info (HomeStars, BBB, etc.)',
  website: 'https://example.com',
  profileInfo: {
    since: 'YYYY',
    warranty: 'Warranty description',
    service: 'Main service description',
    description: 'Profile description'
  }
}
```

## Залежності

- **CSS:** Vanilla CSS (без препроцесорів)
- **JS:** Vanilla JavaScript (без фреймворків)
- **Google Fonts:** Plus Jakarta Sans (400, 500, 600, 700, 800)
- **Icons:** Unicons v4.0.8
- **Жодних NPM пакетів** не потрібно

## Інструкції реалізації

1. Створи файлову структуру з усіма папками та файлами
2. Налаштуй HTML з усіма глобальними елементами (hero, intro, методологія)
3. Напиши CSS з:
   - CSS змінними для кольорів
   - Base стилями (reset, типографія)
   - Компонентами (картки, модалі, кнопки)
   - Responsive дизайном (breakpoints: 820px, 640px, 400px)
4. Напиши JavaScript для:
   - Рендерингу карток компаній
   - Відкриття/закриття профілю
   - Event listeners
5. Створи `companies.js` з пустим масивом `companies[]` (для подальшого заповнення)
6. Залиш коментарі для місць, де потім буде додана інформація

## Стилістичні вимоги

- Кожна картка має затінок при наведенні
- Градієнти на кнопках і hero секції
- Плавні переходи (transition 0.15s)
- Модал з overlay (темний напівпрозорий фон)
- Картка #1 Pick має спеціальну стрічку з інформацією
- Іконки Unicons для всіх декоративних елементів

## Готово до запуску

На завершення:
- Перевір, чи всі файли створені та зв'язані
- Переконайся, що сайт завантажується без помилок
- Картки мають бути готові до рендерингу з пустим `companies.js`
- Структура повинна бути готовою до додавання даних про компанії
